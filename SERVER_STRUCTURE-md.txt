# 15. Security

Database is not publicly accessible.

Redis is not publicly accessible.

n8n is available only through Traefik.

HTTPS is mandatory.

Environment variables are stored in

```
.env
```

Sensitive values include:

- database passwords
- encryption key
- API credentials

These values must never be committed to version control.

# 19. Production Status

Current deployment is a production Docker environment consisting of:

- Ubuntu Server
- Docker
- Docker Compose
- Traefik
- n8n
- PostgreSQL
- Redis
- Gotenberg

The architecture separates application, database, queue, reverse proxy and PDF generation into dedicated containers with persistent storage.
