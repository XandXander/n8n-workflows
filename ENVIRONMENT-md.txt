# Environment Variables

The runtime configuration is stored in

```
/opt/beget/n8n/.env
```

The file contains:

- PostgreSQL configuration
- Redis configuration
- n8n configuration
- Webhook configuration
- Encryption key
- Credentials
- API keys

Sensitive values must never be:

- committed to Git
- exported into documentation
- included in prompts sent to external LLMs

Always replace secret values with

```
<REDACTED>
```

when sharing configuration.

# Security

HTTPS is mandatory.

Redis is not exposed.

PostgreSQL is not exposed.

n8n is available only behind Traefik.

Secrets are stored exclusively in

```
.env
```

Binary data is stored on the filesystem.

Workflow encryption uses the n8n encryption key stored in

```
N8N_ENCRYPTION_KEY
```

# Resource Constraints

The environment is optimized for:

- one production instance of n8n
- one worker
- PostgreSQL
- Redis
- Traefik
- Gotenberg

Available resources are limited.

Any future extensions (additional workers, local LLMs, vector databases, monitoring stacks, etc.) should be evaluated against the available CPU, RAM and disk capacity before deployment.
